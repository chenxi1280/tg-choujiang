## 1. 合同范围

本文补齐 V2.2 的创建者和参与者操作闭环。业务公式、资格和账本语义以主 PRD 为准；页面层级、按钮、草稿保存、分页、异常恢复和发布状态以本文为准。两份文档冲突时不得自行选择实现，必须先修正文档。

## 3. 通用按钮规则

### 3.1 创建者按钮安全

创建者页面只在机器人私聊中工作，并保持一个当前可编辑面板。所有 `draft_*` 回调使用服务端短令牌，绑定：

- 操作人；
- 私聊 chat；
- `draft_id`；
- `draft_revision`；
- 当前 `panel_message_id`；
- 具体 action 和最小对象 ID。

令牌单次消费并保留当前 10 分钟有效期。每次有效操作后重绘面板、递增交互 `panel_revision` 并签发新按钮；业务 `rule_revision` 只有显式保存规则时才递增。重复点击同一 Update 必须幂等；第二次独立点击旧按钮显示“页面已更新或操作已过期”，并提供 `[打开最新页面]`，不能重复执行。

按钮回调先结束 Telegram 客户端 loading，再完成查询/编辑；耗时检测页面先显示“正在检测”，完成后重绘结果。

### 3.2 参与者按钮安全

参与者按钮绑定 Campaign 公共引用和点击用户。查看个人链接、邀请进度或发言进度时，服务端必须联合校验 Campaign、Participant、点击用户和目标参与群，不能返回他人的链接或进度。

群内不能直接私聊未 `/start` 过机器人的用户。“我的加成”使用机器人私聊深链；进入私聊后再做身份和报名校验。

### 3.3 布局与分页

- 群选择、逐群规则、复制目标、邀请链接和逐群进度统一每页 6 个群。
- 翻页保存跨页选择；页码越界提示页面已变化并返回第 1 页。
- 同名群的按钮显示“截断标题 + `@username`”；无 username 时显示 chat ID 后 4 位。正文问题详情始终显示完整标题。
- 每行最多放两个短操作；完整群标题不与其他动作挤在同一行。
- Telegram 没有真正 disabled 的内联按钮。不可用项显示为正文状态，或使用可点击的 `[⚠ 群名｜查看问题]`；不得提供看似可点但无行为的按钮。
- `callback_data` 只放短引用或服务端令牌，不编码完整 UUID、群列表或整份规则。

## 4. 创建者群选择

### 4.1 群选择页

```text
👥 选择参与活动的群
已选 3 个；第 1/2 页

可选择：
[✅ A 群]
[⬜ B 群]

暂不可用：
[⚠ C 群｜机器人不是管理员]
[⚠ D 群｜缺少邀请权限]

[全选本页] [清空本页]
[← 上一页] [下一页 →]
[🔄 重新检测]
[✅ 完成选择]
[↩ 返回抽奖预览]
```

交互合同：

1. 点击可用群立即保存勾选状态并重绘当前页。
2. “全选本页”只选择本页 `selectable` 群；“清空本页”不影响其他页。
3. 未选择任何群时点击“完成选择”，弹窗提示“请至少选择一个参与活动的群”，页面不跳转。
4. “重新检测”显示检测中状态，逐群实时复核后返回新增、恢复、失效数量。
5. 新加入草稿的群，其邀请和发言加成均为关闭；不自动复制其他群规则。

### 4.2 群问题详情

点击不可用项进入：

```text
⚠ C 群暂不可用
原因：机器人已在群内，但不是管理员。
处理：请在群管理中把机器人设为管理员。

[查看完整修复步骤]
[🔄 重新检测 C 群]
[↩ 返回群列表]
```

`creator_not_admin` 只提示创建者恢复自身权限；`occupied` 显示冲突活动但不暴露其他用户隐私；`check_unknown` 显示“Telegram 暂时无法核验”并允许重试。

### 4.3 移除已配置群

移除同时开启了邀请或发言加成的群时，不直接删除：

```text
移除「A 群」？
该群已配置邀请和发言加成。确认后将删除本草稿中的两套设置。

[确认移除并删除设置]
[取消]
```

确认后删除该群两类草稿规则；同一草稿重新加入时从关闭状态开始，不恢复已删除规则。未配置群可直接移除。

## 5. 抽奖加成入口

```text
🔋 抽奖加成

[👥 邀请加成｜2/10 群开启]
[💬 发言加成｜3/10 群开启]
[↩ 返回抽奖预览]
```

分类按钮进入逐群列表。群行状态统一为 `关闭`、`配置中`、`已配置`、`权限待修复`。只有 `已配置` 或 `关闭` 可通过发布配置完整性检查；`配置中` 必须继续设置或取消。

## 6. 逐群邀请加成

### 6.1 邀请群列表

```text
👥 逐群邀请加成｜第 1/2 页

[✅ A 群｜每2人+1｜不限]
[✅ B 群｜每3人+1｜上限5]
[⬜ C 群｜关闭]
[⚠ D 群｜权限待修复]

[← 上一页] [下一页 →]
[↩ 返回抽奖加成]
```

点击群进入独立编辑器；点击权限项进入问题详情。

### 6.2 邀请规则编辑器

进入编辑器时从已提交规则建立私有 working copy。页面内所有增减、预设、上限切换只改 working copy；这些操作可以推进 `panel_revision`，但只有 `[✅ 保存设置]` 才原子写回草稿并递增业务 `rule_revision`。

首次开启预填建议值“每 2 人 +1、不设上限”，但仍需点击保存，不因打开页面自动启用。

```text
👥 A 群邀请加成
状态：开启

每多少人 +1：2
[−1] [当前2｜输入] [+1]
[1人] [2人] [3人] [5人] [10人]

上限：不设上限
[✅ 不设上限] [设置上限]

[复制设置到其他群]
[✅ 保存设置]
[取消修改]
[关闭本群邀请加成]
```

选择“设置上限”后显示：

```text
上限次数：20
[−1] [当前20｜输入] [+1]
[1次] [5次] [10次] [20次]
```

有限模式没有有效上限值时点击保存，提示“请先设置上限次数”并留在当前页。切回不限模式保留 working copy 中最后一个有限值，之后再切回可恢复，但发布规则在不限模式下保存空上限。

“关闭本群邀请加成”只将 `enabled=false`；草稿保留最近参数供重新开启，发布时不创建该群个人链接。“取消修改”丢弃 working copy。working copy 已变化时通过其他导航离开，先显示 `[放弃修改] [继续编辑]`。

### 6.3 自定义数字输入

点击“当前值｜输入”进入专用输入状态：

```text
请回复一个正整数。
[取消输入]
```

合法输入更新 working copy 并返回原编辑器；0、负数、小数、空白或非数字显示具体错误，不覆盖旧值、不离开输入状态。输入状态只接受当前用户当前字段，其他消息不被误当作配置。

### 6.4 复制邀请设置

只能从已保存的完整规则发起复制。working copy 有未保存变化时点击复制，提示“请先保存当前群设置”，不能把未提交值直接写入其他群：

```text
把 A 群邀请设置复制到：
[✅ B 群｜将覆盖现有设置]
[⬜ C 群｜当前关闭]
[⚠ D 群｜权限待修复]

[全选本页] [清空本页]
[← 上一页] [下一页 →]
[继续]
[取消]
```

确认页完整显示来源、目标数量、有限/无限模式：

```text
将覆盖 2 个群的邀请设置。
[确认覆盖 2 个群]
[返回选择]
[取消]
```

确认后为每个目标创建独立规则副本；后续修改 A 不联动目标群。权限待修复群不能被选作目标。

## 7. 逐群发言加成

### 7.1 发言群列表

布局、分页、问题详情和复制目标选择与邀请加成一致。群行摘要必须同时显示消息数、最低字数和每日上限，例如：

```text
[✅ A 群｜10条/≥20字｜日上限1]
[✅ B 群｜20条/≥5字｜每日不限]
[⬜ C 群｜关闭]
```

### 7.2 发言规则编辑器

发言编辑器同样使用 working copy 和原子保存。首次开启预填“每 10 条 +1、每条至少 5 个可计数字符、每日上限 1 次”，不因打开页面自动启用。

```text
💬 A 群发言加成
状态：开启

每轮消息数：10
[−1] [当前10｜输入] [+1]
[5条] [10条] [20条] [50条]

每条最低字数：20
[−1] [当前20｜输入] [+1]
[1字] [5字] [10字] [20字]

每日上限：1次
[不设上限] [✅ 设置上限]
[−1] [当前1｜输入] [+1]
[1次] [5次] [10次] [20次]

[复制设置到其他群]
[✅ 保存设置]
[取消修改]
[关闭本群发言加成]
```

有限/无限、输入、取消、离开脏 working copy、关闭和复制规则与邀请编辑器一致。群禁止普通成员发文本或机器人无法接收消息时，保存被阻止并进入权限修复页。

## 8. 创建预览与发布

### 8.1 预览按钮

预览首页不展开十个群的全部规则，显示数量和状态：

```text
[参与活动的群｜10个]
[邀请加成｜8个群开启]
[发言加成｜6个群开启]
[⚠ 待处理｜2项]

[🎉 发布抽奖]
[清空配置]
[返回首页]
```

点击数量进入对应详情；“待处理”进入配置不完整和权限问题合并清单，并为每项提供 `[去修复]`。没有问题时不显示该按钮。

### 8.2 发布前复核与确认

点击发布先做全量实时复核。存在任一配置中、权限失败或 UNKNOWN 时不进入确认页，显示全部问题和 `[逐项修复] [🔄 重新检测全部] [返回预览]`。

全部通过后显示：

```text
发布前确认
参与群：10个
邀请加成：8个群开启，其中3个不设上限
发言加成：6个群开启，其中2个每日不设上限
权限异常：0项

[查看全部规则]
[确认发布]
[返回修改]
```

“确认发布”使用单次令牌。点击后立即将草稿置为 `publishing`，旧配置按钮全部失效，页面显示 `[🔄 刷新发布状态]`，不能再次创建 Campaign。

### 8.3 发布状态与重试

活动只有全部选中群活动卡确认送达后才进入 RUNNING。页面区分：

- `publishing`：仍在投放；
- `partial_failed`：部分群明确失败；
- `unknown`：远端结果未知；
- `published`：全部确认；
- `blocked`：权限或运行条件阻断。

```text
发布状态：2/3 群确认，1 群失败
[查看失败群]
[重试明确失败群]
[🔄 刷新发布状态]
[返回抽奖管理]
```

重试只复用同一 Campaign、同一冻结 revision，并投递明确失败且未确认的群。UNKNOWN 必须先查询/对账，未形成明确失败前不重发。刷新不产生新投递。

## 9. 参与者页面

### 9.1 群活动卡

```text
[🎟 立即参与]
[📋 参与条件] [🔋 我的加成]
```

未开启任何加成时隐藏“我的加成”。按钮从群进入机器人私聊深链；私聊校验当前用户和 Participant 后显示：

```text
🔋 我的加成
[👥 邀请加成]
[💬 发言加成]
[🔄 刷新]
[↩ 返回活动]
```

只开启一种加成时直接进入对应页面，减少一步。

### 9.2 逐群邀请链接生命周期

邀请群列表每页 6 项。个人链接按 `(Campaign, Participant, participation_group)` 懒创建，不在发布时批量创建。

状态与按钮：

| 状态 | 展示与按钮 |
|---|---|
| `not_created` | `[生成 A 群邀请链接]` |
| `creating` | “正在生成”；`[刷新状态]` |
| `active` | `[复制链接] [转发给好友] [刷新进度]` |
| `permission_failed` | `[查看原因] [重新检测]` |
| `retryable_failed` | `[重试生成]` |
| `cutoff_closed` | 明示“不再计算加成”；只保留 `[打开群聊]` |
| `revoked` | 明示已撤销，不展示 URL |

`active` 页面：

```text
A 群邀请加成
每2人 +1，不设上限
有效邀请：5人；已获得2次；距下一次1人

https://t.me/...
[复制链接] [转发给好友]
[🔄 刷新邀请进度]
[↩ 返回群列表]
```

“复制链接”使用 Telegram `copy_text` 能力；“转发给好友”沿用 Telegram share URL。创建中、失败和重复点击不得创建第二条活动个人链接。

### 9.3 逐群发言进度

```text
今日发言加成｜第1/2页
[A 群｜10/10｜已达上限1/1]
[B 群｜45条｜完成2次｜每日不限]
[← 上一页] [下一页 →]
[🔄 刷新进度]
[↩ 返回我的加成]
```

点击群显示已计数、拒绝口径、距下一轮数量和最后统计时间。权限异常时显示“该群当前无法计数”，提供 `[查看原因] [重新检测]`，不展示假增长数字。

## 10. 权限故障与提醒范围

### 10.1 草稿阶段

任一选中群权限不满足时禁止发布。创建者在选群、保存该群加成、预览待处理清单和发布复核四处都能进入同一修复页。

### 10.2 运行阶段

任一必需参与群失权后 Campaign 进入 `OPERATION_BLOCKED`，但不删除已确认 Participant、链接、消息事实或票账本：

- 新报名因全部参与群资格无法确认而阻断；
- 已报名用户在其他正常群产生的逐群邀请和发言事实继续独立记录/结算；
- 故障群无法观察的消息不得补造，页面明确提示该群暂停计数；
- 开奖快照和结果发布必须等待全部必需群资格恢复为可确认状态；
- 恢复后重新核验资格和截止前事实，再解除阻断。

没有权限恢复事实时不得自动降级资格、跳过故障群或照常开奖。

### 10.3 提醒对象与按钮

运行期主动私聊 Campaign 创建者一次，并按“Campaign + 群 + 权限状态”去重；其他管理员不批量私聊，其打开管理页时显示阻断横幅。创建者提醒按钮：

```text
[查看修复步骤]
[🔄 重新检测该群]
[查看活动阻断详情]
```

参与者只在主动报名、补群、获取链接或查看进度时收到交互提醒：

```text
[🔄 重新检测]
[查看其他缺失群]
[↩ 返回活动]
```

参与者文案必须区分“你未加入”“等待管理员批准”“机器人权限异常”“Telegram 暂时未知”。

## 11. 按钮级验收矩阵

自动化和真实客户端 E2E 至少覆盖：

1. 群列表翻页、跨页保留、全选本页、清空本页、0 群完成、同名群识别。
2. 不可用群问题详情、重新检测、权限恢复和 UNKNOWN 不误判。
3. 邀请/发言编辑器 working copy、保存、取消、脏页面离开确认和关闭后恢复参数。
4. 预设值、`±1`、自定义正整数、非法输入和取消输入。
5. 有限/无限反复切换，空有限上限不能保存。
6. 复制设置跨页选择、覆盖提示、确认、取消和独立副本。
7. 删除已配置群确认；取消不丢规则；确认后重加默认关闭。
8. 旧 panel、过期令牌、重复点击、双击和页面 revision 变化。
9. 参与者未 `/start` 深链、非 Participant、他人链接隔离。
10. 逐群链接未创建、创建中、成功、复制、转发、权限失败、重试、截止和撤销。
11. 逐群发言进度分页、刷新、最后统计时间和权限异常不显示假数字。
12. 单群运行期失权时新报名阻断、正常群继续记录、故障群不补造、开奖阻断和恢复复核。
