# 两个官方频道、加成进度提醒与群分享（2026-10-21）

本修订覆盖 V3.3 中新发布活动的官方频道数量、分享入口及进度通知内容。用户最新确认的入口为精选频道、官方抽奖频道和现有 Bot，不增加客服入口，不合并频道。

## 参与条件

- 新策略 `official-v2` 必须且只包含 `navigation`、`featured` 两个不同的官方频道身份，并要求启动当前 Bot。使用说明继续由 Bot 帮助及原频道提供，不是新版平台必备关注项。
- `official-v1` 保留原三个官方频道的解析和执行能力。新策略只在新发布活动冻结；不追改历史活动的目标、规则、参与人或开奖快照。
- 新创建/复用草稿以当前策略生成只读平台条件。发布前检查频道身份、入口及 Bot 管理员权限；登记、重新核验及开奖前继续核验关注和启动事实。
- 未关注、未启动不能放行；无法核验、权限故障和限流继续使用现有阻断/重试机制，不静默降级。
- 部署配置见 `.env.platform-potato.example`。该文件只包含公开频道身份。它需要和支持 `platform:official-v2` 的新镜像一起应用，不能提前覆盖旧镜像的配置。关闭策略不会解除已发布活动冻结的要求。

## 门槛与人品加成

同一条有效发言分别推进门槛和人品加成，不相加要求，也不因门槛完成额外赠送奖励。同群 5/5 发到 5 条同时完成；10/5 发到 5 条时加成暂存且有效次数为 0，发到 10 条后门槛完成并生效两轮奖励；5/10 发到 5 条后门槛完成，提醒人品还差 5 条。

已有群内完成通知附加各配置群的今日人品加成进度、已完成轮数、下一轮还差条数及奖励次数。沿用原消息/活动/成员幂等键；同一条发言触发的门槛和奖励事件合为一条通知。各群门槛仍分别计算，未完成的群继续列出。保留历史每日上限，达到上限不再引导无奖励发言；截止通知不引导继续累计。

计数刷新后再构造提醒，保证包括触发通知的当前消息。此调整不改变有效发言、统计起点、北京时间自然日和重复消息去重规则。提醒发在事件来源群并提及本人，不新增私聊批量推送。

## 分享

- 获取分享卡片继续通过原 Outbox 发到请求者私聊，不自动登记。卡片保留正文参与链接、URL 参与按钮及「分享到群」。邀请/加成按钮使用同场 Bot 深链，避免依赖原消息回调。
- 「分享到群」调用 Telegram 内联选择器，只允许选择群；选择群后由用户点选结果发送。返回原封面（有封面时）、原样公告正文、正文链接和完整键盘。无封面时为原生文字卡片。
- 查询只接受 `share_<22位公开活动ref>`，不列举活动，不接受内部 UUID。每次查当前状态，不返回草稿、发布中、取消、已开奖或截止活动；`cache_time=0`、`is_personal=true`。查询不产生报名、奖励或发布回执。
- InlineQuery 继续先入 Inbox 再处理。仅针对同一查询 ID 的明确过期拒绝记录 UI response rejected 并结束该条；网络异常和其他错误仍保留原错误及重试语义，避免过期查询永远阻塞后续更新。
- BotFather 必须先启用内联模式；能力以 `getMe.supports_inline_queries` 独立回读。内联卡片发送不等于机器人群内主动发布，也不计邀请归因；目标群仍受 Telegram 权限限制。
- 用户可能在查询后、发送前跨过截止时间。已发出的副本不自动更新；参与链接始终重新检查当前活动状态，不允许因此补报名或绕过截止。
- 长按原消息转发继续保留；复制正文或普通 `t.me/share/url` 不能承诺携带按钮。
