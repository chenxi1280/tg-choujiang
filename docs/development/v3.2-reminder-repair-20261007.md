## 修复结果

1. 开放活动的正式群卡及分享卡保留原活动参与链接，增加「邀请入口」「我的加成」回调；已关闭的分享卡只提供活动状态与规则入口。
2. 未报名成员在有本群发言门槛或发言加成的统计窗口内发言时，发送临时群提醒，提及本人、标明活动、说明本条未计本人进度，并提供同一活动的参与链接。不自动登记或补记报名前的发言。
3. 同活动、同用户、同群五分钟内最多一次未报名发言提醒；消息重放及并发不重复。机器人、服务、转发、命令、空内容、无本群任务、统计窗口外及当前已截止不触发；已有报名但资格失败不误报未报名。
4. 邀请/加成前置错误的群提醒提供本活动参与链接。邀请回调及翻页只把个人入口和明细发给点击者的私聊；私聊不可达时明确提示打开机器人，不向群公开个人链接。
5. 仅开启邀请门槛、没有邀请加成规则时，邀请入口仍进入逐群门槛链接；不错误进入旧单链接分支。

发言提醒与原发言处理共用活动锁及事务，通过现有 Telegram Outbox 投递；仍保留旧邀请规则要求的受邀人发言核验。所有临时提醒继续使用现有删除策略：只有真实消息 ID 和已确认发送 Attempt 才安排确认时间 +15 秒的删除任务。达标和结果等持久通知不改变。

参与链接使用 Worker 启动时校验 Bot 身份取得的用户名，不在提醒发送期间另发身份查询。本次没有数据库结构迁移。
