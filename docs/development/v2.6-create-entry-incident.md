# 创建入口无响应修复

2026-09-05，用户报告线上“创建抽奖”点击无响应。

## 当前事实与原因

- 生产为 d608183，服务健康、Inbox 无积压。三次真实 nav:create 点击 162316244–246 均已处理，操作者没有 group_admins 有效记录，也没有产生 AdminSession。
- CampaignCreator._new_draft 在群列表为空时直接拒绝，违背 V1.9“无草稿时立即创建空草稿并显示预览”的合同。
- 普通回调先发送空 answerCallbackQuery，异常又依赖第二次弹窗，私聊没有持续可见的错误消息，因此用户观察为没有反应。

## 修复合同

1. 无可管理群也可以打开和保存个人空草稿，设置标题、奖品等内容；这不创建 Campaign、发送群卡或授予任何群权限。
2. 预览继续列出缺少参与群。群列表为空时明确说明需要自己和机器人均具有目标群管理员身份，再刷新；不展示无对象可操作的全选、清空和完成选择。
3. 选群和正式发布仍走现有实时权限与输入验证；未选群无法发布。中奖指定仍只允许原配置或数据库名单，创建草稿不影响运维授权。
4. 私聊回调业务校验失败时发送明确的“操作未完成”消息并记录错误类型，保留草稿；不再只依赖已应答的按钮二次弹窗。群回调保留群内弹窗反馈，避免把私聊文案发送到公共群。
5. 回归零群新建、零群继续、有群新建、有效会话与按钮、未选群发布拒绝、私聊可见错误及群回调反馈。正常 CI → release → 精确线上版本和真实客户端点击验收。
