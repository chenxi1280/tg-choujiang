# 提醒群链接与活动卡转发入口（2026-10-29）

本修订覆盖活动进度提醒的群名展示、活动卡及发布回执的参与链接展示，以及新发送活动卡的分享按钮。报名、资格核验、发言计数、票数、活动链接和邀请归因沿用原合同。

## 群名跳转

- 发言门槛和人品加成提醒中的群名，按本场冻结群身份分别生成链接；同名群也不能互相串链。
- 有公开用户名或公开群链接时直接进入该群；私有超级群有已确认投递的本场公告时，链接到该群的公告消息，已入群成员可从中继续发言。
- 没有可确认的直达地址时，使用本场对应群的条件入口；无法生成对应入口时保留文本，不拼造链接。已迁移群不把旧消息编号套用于新群。
- 不公开私有邀请链接，不改变已入账的发言、门槛和加成。既有历史提醒不重发。

## 活动分享

- 活动卡和发布回执中的参与地址显示为可点击的“点击参与”，仍指向本场 `join_<活动ref>`；临时参与提醒使用同样的文字。活动卡的参与按钮与正文保持同一地址。
- 新发送的群公告、私聊分享卡和内联分享卡，整组按钮只使用 URL，包括参加、邀请入口、我的加成及已配置的群文件夹入口；保留原有资格检查。
- 在 Bot 私聊获取分享卡后，可以长按该卡转发到群或频道。分享提示中的独立按钮也可选择群或频道，通过内联卡片发送；获取和分享本身不登记。
- 已截止或关闭的待发分享卡按现有投递时状态改为规则与结果入口，同时兼容旧格式的排队卡片。
- 已经发出的旧公告不会因部署代码自动更换按钮；旧活动可重新获取一张新分享卡。复制正文、频道内容保护和 Telegram 客户端实际表现仍须分别核实。

Telegram 的 [Bot API 更新记录](https://core.telegram.org/bots/api-changelog#may-31-2019)说明：普通转发的 Bot 消息要保留整组内联键盘，需要按钮均为 URL 或登录 URL。代码与隔离测试只能确认发送参数，不能替代真实客户端的频道转发验收。
