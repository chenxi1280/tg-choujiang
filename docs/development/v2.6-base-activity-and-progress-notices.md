# V2.6 基础连续发言门槛与进度提醒

本次范围：新增基础门槛配置、逐群连续发言统计、加成暂存与开奖资格隔离，以及对应用户提醒。各配置群分别达标的口径已经确认。本文件覆盖早期合同中与本次变更冲突的展示及资格条款，其余合同继续有效。

## 基础门槛

- 创建入口：准入条件 → 基础连续发言门槛。
- 每个参与群独立配置连续天数、每天有效消息条数和每条最低字数。例如 `1 7 5 5` 表示页面第 1 个群连续 7 天、每天 5 条、每条至少 5 个可计数字符。
- 发送设置立即保存该群配置，页面明确展示保存语义；可以继续设置其他群。`1 0` 关闭第 1 个群的门槛。
- 未配置基础门槛的群不参与基础门槛判定。配置的所有群都完成后，才能参与开奖。
- 每天按北京时间 `Asia/Shanghai` 自然日统计。任何一天未完成都会中断连续天数；完成一次完整连续周期后，保留本期该群达标资格，不要求一直连续到开奖。
- 用户先完成报名登记及原有成员资格核验，再累计本期发言。机器人无法补采历史消息，不回填历史发言。
- 基础门槛与发言加成分别按各自最低字数判定，互不替代。关闭发言加成后，基础门槛仍然计数。
- 沿用有效消息口径：文本/非空 caption、有效字符数、非机器人/服务/转发/命令；同活动、同用户、同群、冻结去重窗口内相同标准化文本只计一次。重复 Update 不重复记账。
- 参与群移除时移除其未发布门槛配置；发布时冻结规则。开启和发布时复核群发言权限。

## 加成与开奖

`成员及其他原有条件合格` 与 `基础连续发言已达标` 是独立状态。

- 已登记并通过原有条件的参与者，可在基础发言门槛尚未完成时累计邀请和发言加成。
- 加成仍写入原有追加式票账本；未达基础门槛时标为暂存，有效抽奖次数为 0。
- 所有基础门槛完成后，原账本加成生效，不重发票、不复制账本。原有其他资格仍然必须通过。
- 邀请一经确认有效，其计奖人数和已经获得的加成保留；邀请人或被邀请人后续退群、邀请链接过期或撤销均不扣回加成。未达到基础门槛的已获加成同样保留为暂存，不跨活动结转。
- 首次确认前仍须满足留存、真实新成员及现有归因要求；未确认就退群不会凭空获得奖励。已确认者退群重进不重启留存验证、不重复加票，重复入群或申请事件不得覆盖已确认资格。
- 邀请人自身退群可能影响其原有参与资格，但不扣减已获得的邀请加成；能否参与开奖仍独立检查全部基础条件。
- 定时开奖的资格筛选、满人候选触发、满人复核、周期对账及有效人数展示均排除未达基础门槛者。
- 开奖快照只接收已通过全部条件的参与者与对应账本权重；已经冻结的历史快照不修改。

例：用户基础 1 次，发言加成 3 次、邀请加成 2 次。门槛未完成时展示累计 6 次，其中加成 5 次暂存，有效抽奖次数 0；全部门槛完成且其他资格有效后，有效抽奖次数为 6。

## 通知矩阵

| 事件 | 触发时机和内容 |
|---|---|
| 当天基础发言完成 | 该群该自然日第一次达到条数时，显示日期、条数、连续天数及该群是否达标 |
| 全部基础门槛完成 | 首次完成时提醒可参与抽奖，说明暂存加成生效及当前次数 |
| 发言加成增加 | 每次账本目标增加时，在对应群提醒本次增量、当前总加成和生效/暂存状态 |
| 邀请加成增加 | 有效邀请完成留存等原有校验并产生加成时，在归因群提醒；不把刚入群直接当作有效邀请 |
| 连续发言中断 | 未达标用户断档后再次有效发言时提醒重新累计；不是午夜定时催促 |
| 截止后仍未达标 | 结算排空与资格复核通过后，通知本期不能参与开奖，累计加成保留记录但本期不生效 |
| 报名/重复参与/个人记录 | 展示基础门槛、逐群进度、暂存与有效次数；不能仅以“符合成员条件”声称可开奖 |

提醒采用 Telegram 用户 ID 的 HTML 提及，无用户名也可明确提及身份。内容转义，启用消息通知并附“查看我的进度”按钮。逐群事件在对应群发出；活动级截止提醒投递到配置中的一个活动群，避免跨群重复刷屏。不会因关闭原有扩展提示而关闭以上必要状态提醒。

通知与业务变更同事务进入 Telegram Outbox。业务幂等键包括对应参与者、群、日期或账本变更；失败、未知和成功沿用现有 Outbox/Attempt 状态，不吞异常、不因远端未知盲目重发。消息入队不等于 Telegram 已投递，用户端提醒还受客户端通知设置影响。
