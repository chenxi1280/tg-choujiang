## 问题与行为

用户看到的正整数错误对应R10主动发送0的测试；只读Inbox最新仍为Update162317836，
没有捕获新的用户数字提交。此前有效7确已处理，但仅更新12:55的旧面板，最新消息仍是
错误提示，且有效值要再暂存/保存整场。此为可复现反馈缺口，不宣称所有网络延迟的唯一根因。

本群发言条数/邀请人数改为5、8、10、自定义；连续天数保持1、3、7、自定义。
可在已选群编辑页直接回复正整数；有明确待输入字段时修改该字段，否则修改人数/每日条数。
点击快捷值、回复数字或“保存本群门槛”直接保存本群到未发布草稿的实际admission，
保留其他群已保存规则和未提交编辑；干净已保存列表不再要求第二次整场保存。
共享留存冲突、24小时、权限和门槛可完成时间沿用原实时校验，不自动发布活动。

有效/非法输入都在最新回复显示当前群、参数、已保存/未保存与快捷/返回入口。
非十进制、0、负数、小数、超长整数明确拒绝，保留字段和原值；错误后可直接重试。
保存先于回复，面板ID确认后才切换到新面板；同Update重试恢复已保存/错误结果，不再解析数字；
回复旧面板不能改当前群/字段；群列表、搜索、复制、待确认步骤不能猜测目标。
Telegram显示失败继续原Inbox恢复与日志，不把未知送达称为确认。

## 统一风格及排版

沿用星光与成长：✨ 活动、🌱 活跃、🤝 邀请、🧭 条件、🚪 门槛、📷 封面、📦 奖品、
📝 说明、🗓️ 时间、🧑‍💼 发奖、💾 保存、↩️ 返回；成功/警告/选中状态独立表达。
语义图标通过共同UI样式函数覆盖创建器、首页、帮助、个人设置、创建列表、成员详情/门槛/
加成/记录及管理确认。选中标记保留，数值减/当前/加以及短数字预设保持短标签。
样式处理只更新按钮text，不改callback、URL、copy_text、用户输入、行结构、权限与状态来源。
成员来源识别使用去除展示图标后的动作名，避免返回图标破坏路径；重复应用样式不重复加图标。

创建预览基本信息去掉多余空行，功能段保持一空行，保留用户说明原始换行。
条件/封面/更多/奖品标题、群加成与数字上下文补齐语义图标；公告参与按钮替换旧指示表情。
修复R10的规则页标题、复制分页、奖品危险操作分区仍包含在此次版本。
