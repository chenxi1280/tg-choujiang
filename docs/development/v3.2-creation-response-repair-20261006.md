## 源码诊断

- 参与群页每群依次检查Bot身份、创建者身份、群类型；6群最多18次串行远端查询，随后逐群载入全部活动对象，仅用其数量。选群、翻页、刷新都会经过此链路。
- 全选本页逐群检查，包括已经选中的群，随后重新渲染列表。
- 普通成员发言权限检查依次查询群、Bot、创建者；门槛/发言加成/邀请加成同群叠加时重复检查同群。
- 创建回调已有提前回应；Inbox按更新顺序串行处理，前一操作的远端等待会延迟后续点击。此次减少创建处理链路中的串行与重复读取，保留Inbox排序、失败暴露和重试语义。
