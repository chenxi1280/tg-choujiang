# 精选频道自动推送与每日汇总（2026-10-29）

## 用户确认的规则

- 目标是现有精选频道 `@potato_lottery_featured`；本轮不向导航频道重复发送。
- 所有通过本 Bot 在群内发布成功、仍开放报名的活动均收录，不做人工审核或群白名单。
- 群公告收到 Telegram 确认且活动完成发布后，定时扫描生成一次精选推送。
- 每日北京时间 10:00 汇总仍可参与的活动，每页最多 4 场。没有活动时不发空列表。
- 所有活动都包含测试活动；不根据活动名称静默过滤。

## 实现合同

复用 ScheduledJob、Worker 租约及 Telegram Outbox，不新增中间件或数据库表。扫描间隔 30 秒；这是检查间隔，实际送达仍受任务积压、Telegram 限流和网络影响。

只有 `running/scheduled`、未到报名截止且至少有一条群公告 `confirmed` 和远端消息 ID 的活动才能入选。多群活动仍按活动去重；处于 publishing 的部分发布不推广。上线启用后，现有符合条件的活动也会补入，每场一次。

精选消息是简洁文字卡，包含活动名、前三项奖品摘要、前三个来源群名、报名截止和开奖时间。正文「点击参与」与 URL 按钮使用同一个 `join_<public_ref>` 活动入口；完整条件在活动页查看。满人开奖注明满人触发与最晚时间。不输出私有群邀请密文或内部活动编号。

发送前再次读取活动状态及当前截止、开奖时间；如果排队期间已截止、暂停、开奖或取消，改为对应状态和规则/结果入口。已完成开奖时从已保存 DrawRun 读取实际完成时间，避免将原定未来时间展示为已发生的开奖。已确认发送的单场精选卡由后续扫描同步状态并更新按钮。每日汇总是带日期的快照，发送前更新状态，发出后不逐项编辑；参与入口始终重新核验当前条件和截止状态。

活动推送按频道与活动去重，汇总按频道、北京时间日期及页码去重。扫描事务使用 advisory lock；同一个任务重放只产生一个后继任务。网络结果未知继续停留 UNKNOWN，不因下一轮扫描自动补发。新操作沿用已有投递错误记录、限流与连接失败重试。

频道身份、Bot 管理员身份、发帖与编辑权限在扫描任务中核验。失败保留为任务错误，不影响其他开奖任务处理。重启会检查是否已有活动扫描链，避免重复注册；当日 10:00 后首次恢复会补当日汇总，不补往日汇总。

## 配置与发布

默认关闭；仅配置首页精选链接不会启用自动发帖。Compose 已显式传递三项配置，避免 sudo 环境和 env_file 默认值覆盖：

```dotenv
FEATURED_PUSH_ENABLED=true
FEATURED_PUSH_CHAT_ID=-1004477119880
FEATURED_DIGEST_HOUR=10
```

共享生产配置启用应与支持上述操作的镜像一同发布，遵循部署合同。关闭配置停止新增扫描意图，已持久化的 Outbox 不自动删除或改写。配置频道 ID 必须独立核对当前身份及权限。

## 当前核对与验收边界

2026-10-29 生产只读查询：天津音乐学院一品楼联合抽奖的两个群公告确认；另外两场进行中活动各有一条群公告确认。对现有导航和精选频道 ID 查询，没有机器人 Outbox 投递记录。这证明自动推送缺失，不能据此断言没有人手动发过频道消息。

初版阶段仅实现和隔离验证，没有部署、修改生产配置或向频道发帖。后续用户已授权将本功能与提前截止时间修复、提醒精简合并提交发布，启用自动推送和每日汇总，并补推现有活动。真实频道展示、按钮点击、上线后的去重和次日定时汇总须按相同活动、频道、日期窗口验收；实际结果以生产验收记录为准。
