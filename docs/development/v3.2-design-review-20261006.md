## 1. R1十二类设计问题与修正

| 编号 | 初稿设计缺口与具体风险 | 本轮修正 | 主PRD落点 / 新验收 |
|---|---|---|---|
| R01 | 把现状主群授权写成保持规则，单群管理员可能控制跨群整场 | 按既有全参与群管理员交集；主群实现写为差距；本人创建/公开结果只读与敏感管理分开 | §3.2、§8 / AC25 |
| R02 | 暂停/待运行/发布中合并、仅看尚未截止；可能误隐藏原可用能力或引导无法完成任务 | 登记、计数、归因、核验、取入口、分享分别判定；强制门槛可完成性、实际发布确认及晚登记窗口明确；可选奖励无窗口不阻断其他能力 | §6.4、§6.6、§7 / AC26–27 |
| R03 | 运行权限故障被当人工暂停，恢复权限可能误恢复人为暂停或补造消息 | 独立运行阻断覆盖层，具体目标/原因/重检测；正常群与故障群事实分开；不自动解除人工暂停 | §7.1、§8 / AC26 |
| R04 | 活动已创建但发布调用/回执失败，恢复仍进未发布草稿 | 恢复核对活动身份与幂等来源，已有活动进入C18同场处理，创建未知先核查，不二次建场 | §5、§6.1 / AC28 |
| R05 | 发布中取消后可能把UNKNOWN清成未发送，迟到确认又重开活动 | 取消与远端投递独立；保留Attempt/UNKNOWN，迟到确认卡同步取消，不能重开或盲重发 | §8 / AC29 |
| R06 | 返回合同只管页面按钮，命令/深链离开后旧输入状态继续接收文字 | 统一跨模块退出，结束字段接收，保存/放弃作用范围与目的页明确；到期不自动把迟到文本写入新草稿 | §9.2 / AC30 |
| R07 | 即时删群没有清未保存门槛、加成、复制引用 | 确认列全部影响，原子清该群引用，保留其他群编辑；被删来源回模块列表，不允许旧稿复活目标 | §6.2、§9.2 / AC31 |
| R08 | 门槛打开时24小时快照未改，另一入口保存48小时，整场保存仍覆盖回24小时 | 共享字段基线与是否修改分开；未改值同步新基线，双边显式修改展示冲突，不后写覆盖 | §6.4、§9.2 / AC32 |
| R09 | 条件修复只写入群，漏用户名/地区；活动中失格或未知者可能被禁止读已有账本 | 列全部资格项，地区锁定/可修改分别解释并按原活动返回；本人已有记录始终可只读，当前资格不伪造，重新合格不补离群期 | §7.1–7.4 / AC33 |
| R10 | 首次join改详情摘要后，完整条件可能降为次入口或强制阅读门槛 | 登记前完整冻结要求可读，长内容明确分页身份/返回；不自动登记，不新增“读完所有页”条件 | §7.1 / AC34 |

## 3. 定向推演覆盖

1. 仅管理A群的用户尝试取消A+B活动，与全部群有权、某群后来失权/未知分别推演。
2. PUBLISHING、SCHEDULED、PAUSED、运行权限阻断及截止分别叠加本人未登记/缺条件/已获奖励，不用单一开放标志。
3. 最晚计奖时点恰等及晚于边界、有旧邀请待留存、全无可完成事实、多天门槛不足、可选加成无窗口分别推演。
4. 创建事务完成后消息回执中断、已有活动ID与创建结果未知分别推演；取消后迟到确认不会二次开放。
5. 编辑门槛时打开活动深链、24小时过期后迟到输入、删来源群、先24后48小时共享留存冲突分别推演。
6. 地区未设/可改/锁定、用户名缺失、资格未知、重新通过、首次长规则、未开奖取消/缺结果归档分别推演。

上述为R1文档推演，非自动化或客户端测试；R1验收为AC01–AC36，R2扩为AC01–AC48。新场不增加拒绝晚登记、强制读页、时间顺延、自动重发、业务群数限制或模拟成功路径。

## 4. R2统一控件与体验整合

| 问题或遗漏 | 本版最终方案 | 验收 |
|---|---|---|
| 统一控件只写布局，没有每次点击完整合同 | UC01–UC18统一身份、单位、选中、范围、保存、反馈和返回，PT01–PT06统一正文模板 | AC37 |
| 首次创建无下一步，门槛隐藏；组合项直接收输入 | 缺项按推荐顺序直接进入具体页，其他自由编辑；C03/C14先摘要后子操作 | AC38 |
| 奖品半笔保存/取消不明 | 名称仅pending，有效人数才追加；重输、取消、离开恢复与幂等明确 | AC39 |
| 保存一群实际启用全模块，却没说其他规则恢复 | 关闭时“保存并开启本加成”，列所有恢复群；放弃保持关闭，不串另一模块 | AC40 |
| 首页发布恢复占用创建入口，旧场新稿覆盖恢复信息 | C17始终主动新建，原场恢复活动级持久绑定；不要求取消旧场，/new沿旧语义 | AC41 |
| 活动详情/进度重复层级；发言没有任务入口 | M02内嵌M04进度，直接到M09/M05/M06/M07；单选省层，真实origin返回，去本群发言 | AC42 |
| 邀请确认后仍需刷页；宣传/归因容易拿错 | 确认消息直接复制/转发/记录且不抢当前页；分享活动卡片与我的邀请链接语义明确 | AC43 |
| 领奖联系缺上下文、复制易超过原生容量 | 正文完整说明；剪贴板用同活动链接/本人ID/顺位名额短模板，不自动发送或标已领 | AC44 |
| 同名目标不可辨，或把可迁移chat ID当业务身份 | 完整正文+序号/必要尾号；业务绑定稳定Group/参与群关系，调用解析当前路由，群升级不重建进度/归因/奖励 | AC45 |
| 只取前20条再切页的伪全量分页 | 所有有权记录可翻到，21场以上及排序/越界/失权反例，不新增总数上限 | AC46 |
| 旧自动反馈只有概述，私聊规则误伤必要群提醒 | 8类事件/局部提示/同源合并/事务最终次数/重放/日期完整继承；必要群通知与个人查询分开 | AC47 |
| 封面连续替换没有完整往返验收 | 新回执是当前面板，连续替换/完成/清除/旧按钮/退出后图片输入全部覆盖 | AC48 |

UP01–UP08给出首次创建、编辑复制、恢复复用、新用户参与、发言、邀请、宣传领奖、管理异常的完整路径；旧优化逐项映射到同版控件、路径和验收，不保留重复或互相矛盾的产品分支。
